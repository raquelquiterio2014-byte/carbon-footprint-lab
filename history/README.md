# Historical snapshots

These directories preserve available **snapshots**, not independently verified releases for each numbered version.

- `v1-v6-snapshot`: combined project as of V6; individual V1–V5 source trees were not available.
- `v7-initial-snapshot`: initial V7 snapshot.
- `v7-brazil-expanded`: expanded Brazilian factors snapshot.
- `v7.2-brazil`: V7.2 with GHG component calculations.

The repository root contains the latest V7.3 English edition. Earlier snapshots retain their original language for historical fidelity. Do not run older snapshots against the same SQLite database without a backup.
